INSTRUMENT SELF-AUDIT — the decisive caveat (scripts/pink-pixels-floor.mjs, pink-breath-vs-floor.mjs):
  Under reducedMotion:reduce at 9cc06f84 NOTHING animates (phase-E P-6 is green: 0 durations, 0 moved), yet the
  IMAGE is NOT pixel-identical frame to frame. A sub-pixel antialiasing shift on a bright-mark edge flips one
  pixel from ~0.6 to ~0.001 — a huge SINGLE-PIXEL delta. Measured static noise floor: swing_max 0.0319, 11,302
  pixels swing>0.002, mean|Δ| 3.6e-5. CONSEQUENCES, stated plainly because phase F depends on them:
    - Q-F2 raw swing_max (0.0339) is NOT distinguishable from the static floor's max (0.0319). The per-pixel MAX
      and any raw single-pixel threshold are NOISE-DOMINATED. The robust signal is the COUNT of swinging pixels
      and mean|Δ|: signal 74k vs floor 13k pixels>0.002; signal 1.5e-4 vs floor 3.6e-5 mean — the breath is ~5×
      above the floor on both, so it IS real, but small.
    - A 2px blur separates them cleanly: >0.002 count signal 74,259→52,292 (survives) vs floor 13,456→2,225
      (collapses); signal:floor ratio 5.5:1 raw → 23:1 blurred. Blurred breath mean|Δ| ~6e-5, swing_max ~0.011.
    - FOR PHASE F: PF-8's "every mark pixel swing ≤ 0.002" and F-6's ceiling "no pixel over 0.030" CANNOT be
      tested at raw single-pixel strictness — the antialiasing floor alone reaches 0.030–0.032 and 11k pixels
      >0.002 with NOTHING moving. These obligations need an AA-tolerant instrument (area/blur luminance, or a
      per-pixel epsilon / neighbourhood-persistence). A naive raw test false-fails on every build, phase E or F.
      PF-11 ("every pixel identical across ≥2s") has the same problem: it is already false at 9cc06f84 under
      reduce by 11k pixels, none of them moving. This is PINK's first concrete feedback on the §7/§8 corridors.
